🚀 Quick Start

Step 1: Navigate to Project

cd web3-shop

Step 2: Install Dependencies

npm install

Note: You'll need Node.js 20+ installed

Step 3: Configure Environment

cp .env.example .env

Then edit .env with your configuration:

  • PostgreSQL database URL
  • Alchemy/Infura API keys
  • WalletConnect Project ID
  • NextAuth secret

Step 4: Set Up Database

npm run db:push
npm run db:seed

Creates tables and populates with sample Birkenstock products

Step 5: Deploy Smart Contract

npm run contract:compile
npm run contract:deploy

Deploys payment processor to Sepolia testnet

Step 6: Start Development Server

npm run dev

Open http://localhost:3000

🎉 Success! Your Web3 shop is now running locally with crypto payment capabilities.
